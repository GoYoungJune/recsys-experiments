# 사전 등록: ml-1m CTR(클릭 확률) 예측 실험

> 이 문서는 **평점(라벨)을 열어 보기 전에** 작성하고 커밋했습니다. 분석 전에 확인한 것은 시각 분포와 사용자·아이템 겹침뿐입니다.
> 계획에서 달라지는 것은 이 문서를 고치지 않고 README의 "계획에서 달라진 점"에 적습니다.

## 1. 문제

광고·피드 랭킹은 "이 사용자에게 이 아이템을 보여 주면 반응할 확률"(pCTR)을 예측합니다. 광고 경매는 pCTR × 입찰가로 순위를 정하므로 **순서(AUC)뿐 아니라 확률 값 자체(보정, calibration)**도 맞아야 합니다.

공개된 실제 클릭 로그는 대부분 수 GB라서, CTR 논문들(AutoInt, Song et al. 2019 등)이 쓰는 ml-1m 설정을 따릅니다.
- **라벨**: 평점 4~5 → 1, 1~2 → 0, **3은 제외**합니다.
- **해석**: "평점을 남긴(=노출된) 영화를 좋아할 확률"입니다. 실제 클릭이 아니므로 결론은 모델 구조와 평가 방법에 대한 것으로 한정합니다.

## 2. 데이터와 분할

| 항목 | 내용 |
|---|---|
| 데이터 | MovieLens 1M: 평점 1,000,209개, 사용자 6,040명(성별·나이·직업·우편번호), 영화 3,883편(장르·개봉 연도) |
| 분할 | **전역 시간순**: (timestamp, userId, movieId)로 정렬한 뒤 앞 80% train, 다음 10% valid, 마지막 10% test. 3점 제외는 분할 뒤에 함 |
| 이유 | 과거로 학습해 미래를 예측하는 서비스 상황과 같게. 랜덤 분할은 미래 행동이 학습에 섞임 |
| 분할 구조 (라벨 없이 확인) | valid(2000-12-02~29) 행의 23.8%만 train에 있던 사용자 → 대부분 신규 사용자. test(2000-12-29~2003-02-28) 행의 80.7%가 기존 사용자 |

## 3. 특성 (어휘는 train에서만 만듦, 처음 보는 값은 "모름" 인덱스)

user_id, movie_id, gender, age, occupation, zip 앞 3자리, 개봉 연도(5년 구간), 장르(여러 개 → 임베딩 평균).

## 4. 모델 (하이퍼파라미터는 미리 고정, 튜닝하지 않음)

| 모델 | 구조 |
|---|---|
| LR | 특성별 가중치의 합 (로지스틱 회귀) |
| FM (Rendle, 2010) | LR + 모든 특성 쌍의 임베딩 내적 |
| DeepFM (Guo et al., 2017) | FM + MLP [256, 128] (병렬) |
| DCN-v2 (Wang et al., 2021) | Cross layer 3개 + MLP [256, 128] (병렬) |

공통: 임베딩 16차원, Adam lr 1e-3, 배치 4,096, MLP dropout 0.2, BCE 손실, 최대 30 epoch, **valid logloss 기준 조기 종료(patience 2)**, best 가중치 복원, 시드 42.
재학습 없이 train으로 학습한 모델을 test에 한 번 평가합니다.

**"최고 딥 모델"**은 DeepFM과 DCN-v2 중 **valid logloss**가 낮은 쪽입니다(test를 보지 않고 고름).

## 5. 지표

- **AUC**(순서), **LogLoss**(확률 품질), **ECE**(보정 오차: 예측값 10개 등간격 구간, 구간 크기 가중), **보정 비율**(평균 예측 / 실제 양성 비율).
- **CI는 사용자 단위 cluster bootstrap 1,000회**로 구합니다. 같은 사용자의 행은 서로 독립이 아니므로, 행이 아니라 사용자를 복원 추출합니다. 모델 비교는 같은 재표본을 씁니다(paired).

## 6. 가설과 판정 기준

| | 가설 | 확인 기준 |
|---|---|---|
| **C1** | 특성 간 상호작용이 중요하다: FM > LR (test AUC) | AUC 차이의 95% CI 하한 > 0 |
| **C2** | 딥 모델이 FM보다 낫다: 최고 딥 모델 > FM (test AUC) | AUC 차이의 95% CI 하한 > 0 |
| **C3** | 기간이 바뀌면 보정이 어긋나고, valid로 맞춘 Platt scaling이 test ECE를 줄인다 (최고 딥 모델) | ECE 차이(보정 후 − 전)의 95% CI 상한 < 0 |
| **C4** | train에 없던 신규 사용자의 test 행에서는 AUC가 기존 사용자보다 낮다 (최고 딥 모델) | AUC 차이(신규 − 기존)의 95% CI 상한 < 0 |

C3의 Platt scaling은 valid 예측값의 로짓에 a·z + b를 맞추는 2-파라미터 로지스틱 회귀입니다. AUC는 바뀌지 않습니다.

## 7. 탐색적 분석 (판정에 쓰지 않음)

- 보정 곡선(reliability diagram)
- ID 임베딩(user_id, movie_id)을 뺀 최고 딥 모델: 신규·기존 사용자별 AUC

## 8. 한계 (미리 밝혀 둠)

- 평점은 클릭이 아닙니다. 노출 선택 편향(사용자가 고른 영화에만 평점이 있음)이 있습니다.
- 하이퍼파라미터를 튜닝하지 않았으므로 모델 간 차이는 "같은 고정 예산에서"의 비교입니다.
- valid가 신규 사용자 위주라 조기 종료·보정이 test(기존 사용자 위주)와 분포가 다릅니다. 이것이 C3·C4의 배경입니다.
