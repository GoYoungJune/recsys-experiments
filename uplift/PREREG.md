# 사전 등록: Hillstrom 이메일 실험 분석 계획

> 이 문서는 **결과 열(visit, conversion, spend)을 열어 보기 전에** 작성하고 커밋했습니다. 커밋 기록이 그 증거입니다.
> 분석 전에 확인한 것은 배정 열(`segment`)과 사전 변수(구매 이력 등)의 분포뿐입니다.
> 분석 중 이 계획에서 바꾸는 것이 생기면, 이 문서를 고치지 않고 README의 "계획에서 달라진 점"에 따로 적습니다.

## 1. 실험 개요

| 항목 | 내용 |
|---|---|
| 데이터 | Kevin Hillstrom, MineThatData E-Mail Analytics Challenge (2008). 실제 온라인 의류 쇼핑몰의 무작위 이메일 실험 |
| 단위 | 고객 1명 (최근 12개월 안에 구매한 고객 64,000명) |
| 군 | 남성용 상품 메일(Mens) / 여성용 상품 메일(Womens) / 미발송(Control), 설계 비율 1:1:1 |
| 관측 기간 | 메일 발송 후 2주 |
| 사전 변수 | recency(마지막 구매 후 개월 수), history(지난 1년 구매액), mens·womens(지난 1년 남성용·여성용 상품 구매 여부), zip_code, newbie(1년 안에 가입), channel |
| 배정 확인 | Mens 21,307 · Womens 21,387 · Control 21,306 |

## 2. 지표

| 구분 | 지표 | 사용 |
|---|---|---|
| **1차** | visit: 2주 안에 사이트 방문 (0/1) | 가설 판정에 사용 |
| 2차 | conversion: 2주 안에 구매 (0/1) | 효과와 95% CI 보고. 다중 비교 보정 없음, 판정에 쓰지 않음 |
| 2차 | spend: 2주 구매액 ($) | 같음 |

1차 지표를 방문으로 정한 이유: 구매(conversion)는 드문 사건이라 군당 약 21,000명으로는 개인별 효과 차이(이질성)를 추정할 검정력이 부족할 것으로 예상합니다.

## 3. 품질 점검 (분석 전에 통과해야 함)

- **SRM**(배정 비율 불일치): 1:1:1 대비 카이제곱 적합도 검정(자유도 2). **p < 0.001이면 분석을 멈추고 원인부터 조사**합니다.
- **공변량 균형**: 모든 사전 변수에 대해 각 처치군과 대조군의 표준화 평균 차이(SMD)를 구합니다. |SMD| ≥ 0.1인 변수가 있으면 보고하고 해석에 반영합니다.

## 4. 가설과 판정 기준

유의수준은 양측 α = 0.05입니다.

| | 가설 | 검정 | 확인 기준 |
|---|---|---|---|
| **U1** | 두 메일 모두 방문율을 높인다 | Mens−Control, Womens−Control 방문율 차이. Welch z 검정, **Holm 보정(2개)** | 두 비교 모두 보정 p < 0.05이고 차이 > 0 |
| **U2** | 메일 효과는 "고객이 산 적 있는 상품군"과 맞을 때 더 크다 | ① Mens 메일 효과: mens=1 고객 − mens=0 고객 ② Womens 메일 효과: womens=1 − womens=0. 효과 차이의 z 검정, **Holm 보정(2개)** | 두 비교 모두 보정 p < 0.05이고 차이 > 0. 하나만 확인되면 "부분 확인" |
| **U3** | 업리프트 모델로 고객마다 메일 종류를 고르면, 모두에게 같은 메일을 보내는 것보다 방문율이 높다 | test 세트에서 정책 가치 차이, 고객 단위 paired bootstrap 10,000회 | 95% CI 하한 > 0 |
| **U4** | 예산이 절반뿐일 때, 모델이 고른 상위 50%에게만 보내면 전원 발송 증분 방문의 절반보다 많이 얻는다 (= 무작위로 50%를 고르는 것보다 낫다) | 증분 비율 = [V(상위 50%) − V(미발송)] / [V(전원 발송) − V(미발송)], bootstrap 10,000회 | 95% CI 하한 > 0.5 |

- U1, U2는 전체 64,000명으로 검정합니다(모델 학습이 없는 사전 지정 비교).
- U3, U4는 **test 세트로만** 판정합니다.

## 5. 업리프트 모델 (U3, U4)

- **분할**: 군별로 층화해 50:50으로 train/test를 나눕니다(시드 42). test는 최종 평가에 **한 번만** 씁니다.
- **모델**: T-learner. 군마다 방문 확률 모델을 따로 학습하고, 업리프트를 p̂(방문 | 메일 a, x) − p̂(방문 | 미발송, x)로 계산합니다.
- **후보 2개**: 로지스틱 회귀, 히스토그램 그래디언트 부스팅(HistGradientBoosting: max_depth 3, learning_rate 0.05, max_iter 200, min_samples_leaf 100으로 고정).
- **모델 선택**: train 안에서 5-fold 교차검증을 합니다. 각 fold의 밖(out-of-fold)에서 계산한 U3 정책 가치로 고르며, test는 보지 않습니다.
- **특성**: recency, history, mens, womens, newbie, zip_code(원-핫), channel(원-핫). history_segment는 history를 구간으로 나눈 것이라 넣지 않습니다.

### 정책과 정책 가치

| 정책 | 내용 |
|---|---|
| 모델 정책 (U3) | 고객마다 예측 업리프트가 더 큰 메일(Mens 또는 Womens)을 보냄. 모두 메일을 받음 |
| 단일 메일 정책 (U3 비교 대상) | 모두에게 같은 메일. Mens와 Womens 중 **train**에서 방문율이 높았던 쪽 |
| 상위 50% 정책 (U4) | max(Mens 업리프트, Womens 업리프트)가 큰 순서로 상위 50%에게 더 큰 쪽 메일, 나머지는 미발송 |
| 전원 발송 (U4 분모) | 단일 메일 정책과 같음 |

**정책 가치 추정**: 무작위 배정이라 배정 확률을 알고 있으므로, 층화된 역확률 가중(Hajek) 추정을 씁니다.
V(π) = Σₐ P̂(π(x) = a) · mean{ Yᵢ : Tᵢ = a, π(xᵢ) = a }
즉, 정책이 메일 a를 주라고 한 고객 중 **실제로 a를 무작위로 받은 고객**의 평균 방문율을 a별로 구해 가중 평균합니다.
CI는 test 고객을 복원 추출하는 bootstrap 10,000회로 구하고, 정책끼리 비교할 때는 같은 재표본을 씁니다(paired).

## 6. 탐색적 분석 (판정에 쓰지 않음)

- 단순 규칙 정책: mens만 산 고객에게는 Mens 메일, womens만 산 고객에게는 Womens 메일, 둘 다 산 고객에게는 train에서 더 나았던 메일. 이 규칙과 모델 정책을 비교합니다.
- Qini(업리프트) 곡선: 상위 몇 %에게 보낼 때 증분 방문이 얼마인지.
- 구매(conversion)·구매액(spend) 기준의 모델 정책 가치.

## 7. 검정력 (사전 계산)

1차 지표 기준선(대조군 방문율)을 아직 보지 않았으므로 몇 가지 값으로 계산했습니다. 군당 n ≈ 21,300, 양측 α = 0.025(Holm의 첫 단계로 보수적으로 잡음), 검정력 80%에서의 최소 탐지 효과(MDE)는 다음과 같습니다.
MDE = (z₀.₉₈₇₅ + z₀.₈) · √(2p(1−p)/n) = 3.083 · √(2p(1−p)/n)

| 기준 방문율 p | MDE (절대, %p) |
|---|---|
| 5% | 0.65 |
| 10% | 0.90 |
| 20% | 1.20 |

U2(상호작용)는 하위 집단의 효과 **차이**를 보므로 분산이 약 4배이고, MDE는 약 2배입니다. 검정력이 부족할 수 있음을 미리 밝혀 둡니다.

## 8. 의사결정 규칙 (미리 정함)

| 결과 | 권고 |
|---|---|
| U1 확인 + U3 확인 | 모델로 메일 종류를 골라 발송 |
| U1 확인 + U3 미확인 | 단일 메일 정책 유지 (모델 운영 비용을 정당화할 근거 없음) |
| U1의 한 메일만 확인 | 확인된 메일만 발송 |
| U4 확인 | 예산이 제한되면 모델 상위 고객부터 발송 |

## 9. 한계 (미리 밝혀 둠)

- 이 데이터는 2008년부터 공개되어 여러 사람이 분석했습니다. 분석자가 이미 알려진 결과를 접했을 수 있습니다. 사전 등록은 **분석 방법을 결과에 맞춰 바꾸는 것**은 막지만, 사전 지식까지 없애지는 못합니다.
- 수신 거부·스팸 신고 같은 가드레일 지표가 없습니다.
- 메일 발송 비용이 없어 "보낼수록 이득"인 구조입니다. 그래서 U3은 "어떤 메일을 보낼지", U4는 "예산 제약" 상황으로 질문을 나눴습니다.
